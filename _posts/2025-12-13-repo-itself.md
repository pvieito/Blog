Este blog está construido con Jekyll y alojado en GitHub Pages. El repositorio contiene la estructura típica de un sitio Jekyll con carpetas `_posts` para artículos, `_layouts` para plantillas, `_includes` para componentes reutilizables, y `_sass` para estilos.

Además incluye páginas dedicadas para mostrar aplicaciones desarrolladas, políticas de privacidad y soporte. El sitio utiliza feeds RSS y JSON para sindicación de contenido.
