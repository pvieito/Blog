This app privacy policy is very simple: **your data is yours**.

- If the app includes **sync support**, it uses the system sync service, which is **under your control**.
- If the app stores **health data**, it stores it on-device in the system health service, which is **under your control**.
- If the app requests **screen recording** permission, it uses this capability on-device, and the resulting data always stays **under your control**.
- If the app includes a **subscription** option, an anonymous subscription identifier is sent with any **explicit user request** that requires server-side processing, to validate the subscription status.
- If the app uses **complex processing** techniques, like machine learning or artificial intelligence models, that require sending data off the device to services like OpenAI, only the **data you explicitly select** is sent.

<center><i>Proudly crafted with the <b><a href="https://en.wikipedia.org/wiki/Privacy_by_design">Privacy by Design</a></b> principle in mind.</i></center>
